## 批次目录

批次目录名为 `YYYYMMDDTHHMMSSZ-<git12>`，即 UTC 开始时间加 12 位 Git 提交号。同名目录已存在时脚本停止，不覆盖已有结果。

| 批次内路径 | 保存内容 |
| --- | --- |
| `record.md` | 本批目的、实例与内核、源码提交、执行命令、异常和补测关系 |
| `preflight/` | 实例信息、CPU 拓扑、EPC、CPUID，以及运行中 enclave 的 REPORT 核对结果 |
| `trials.csv` | 一次运行一行，写明实验、配置、档位、状态、有效时长和原始数据路径 |
| `e1/` 至 `e8/` | 各实验每次运行的命令、配置、标准输出与错误、每秒采样和 `metrics.json` |
| `summary/` | `summarize.py` 生成的汇总表和图 |
| `archives/` | 不直接入库的大文件的 xz 压缩副本及还原步骤 |
| `SHA256SUMS` | 收齐原始文件后生成的校验清单 |

每个数值都来自单次运行。补测分配新的运行编号，并写明它对应的原运行。
